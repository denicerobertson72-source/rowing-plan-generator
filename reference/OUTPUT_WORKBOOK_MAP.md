# Existing prototype workbook map

The earlier personalized workbook demonstrated the following useful output concepts. Rebuild these concepts in a new app-owned template rather than copying a third-party workbook design.

- overview with fixed weekly structure and assumptions;
- detailed daily schedule;
- provisional erg reference with HR, watts, split, rate, effort, use, and caution;
- athlete profile and test inputs;
- monthly targets by UT band;
- annual/phase plan;
- daily time budget;
- session menu;
- weekly log;
- sources.

A private example workbook can be supplied to Codex for visual comparison, but it should not be included in a public repository until all embedded third-party content and formulas have been removed or licensed.

- `POWER PROFILE`: measured multi-duration tests, ratios, anchors, longitudinal change, and limitations.
