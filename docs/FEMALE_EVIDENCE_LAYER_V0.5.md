# Female-focused evidence layer v0.5

The app is female-evidence-first and athlete-specific. It contains no sex, menstrual, contraception, menopause, or age multiplier. Actual 2k remains the primary performance anchor; 60-second power is the stronger default short-duration input; seven-stroke peak supports starts and PP work but a small single reading cannot alter the plan.

Every generated plan includes a structured evidence provenance list with F1–F5 population relevance, confidence, origin, applicability note, and prohibited inference. Session RPE load is stored as actual minutes × RPE and shown only as a descriptive personal trend. Strength remains a first-class session and contributes to recovery load, never rowing-zone minutes.

Female-health, contraception, life-stage, HRV, iron, RED-S, and injury data do not automatically alter training. Optional sensitive tracking and athlete-approved recurring-pattern suggestions are deferred to a later milestone.
