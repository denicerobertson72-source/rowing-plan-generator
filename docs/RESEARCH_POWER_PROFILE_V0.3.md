# Research Power Profile v0.3 developer note

The app uses actual 2,000 m ergometer performance as its primary integrated winter performance anchor. Seven-stroke peak power and 60-second mean power are separate, active inputs for short-power monitoring and PP/AN prescription. A 30-minute rate-capped result remains an optional sustained benchmark, not a threshold measurement.

Research supports monitoring multiple rowing efforts and normalizing short-duration power to an athlete's own actual 2k result. It does **not** validate this app's target percentages, training-adjustment rules, or population labels. Those are versioned, conservative app coaching rules. No predicted 2k, universal 60-second divisor, weighted short-test formula, or physiological diagnosis is implemented.

Longitudinal changes are displayed neutrally and should be interpreted alongside normal test variability, training context, recovery, and repeated measurements. Race dates, taper, athlete availability, fixed rest, lifting, and locked weeks always override profile-driven adjustments.
