# Taper and recovery transformation report

The Step 5 layer runs after deterministic Step 4 selection. It retains the
original archetype and structure, then records a role-sensitive reduction.

| Context | Rowing behavior | Strength behavior | Race/recovery behavior |
| --- | --- | --- | --- |
| Normal week | No transformation | Heavy | Normal intent |
| C race | Minimal taper reduction | Heavy where scheduled | Race replaces ordinary training |
| B race | Moderate reduction | Maintenance | Race-rate exposure retained |
| A taper | Low-intensity volume absorbs most reduction; quality quantity reduced | Reduced-load | Race-rate retained, no intensity inflation |
| Multi-day A race | No ordinary quality on race days | Reduced-load before event | Each race day records starts/load; next day is recovery phase |
| Mixed week | Only taper-phase dates transform | Date-sensitive | Build dates remain untransformed |
| Post-race recovery | UT3/technique quantity reduced | No automatic extra lifting | Intentional recovery, not unexplained blank days |

Every transformed session contains original archetype ID and structure, work
minutes before/after, volume factor, changed parameters, reason codes,
athlete-facing explanation, sources and algorithm version. Completed/locked
sessions are restored byte-identically after transformation.
